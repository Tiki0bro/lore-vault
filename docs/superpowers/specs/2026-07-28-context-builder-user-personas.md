This spec references the 5 user personas used to guide the development, UX design, QA automation, and scope evaluation of Lore-Vault features:

1. **Ethen (Product Owner & Project Lead)**: Focuses on feature scoping, progressive disclosure UI, preset workflow modes, token/cost transparency, and project roadmap extensibility.
2. **Riley "Solder" Chen (QA Lead & Edge-Case Specialist)**: Focuses on automated integration suites, boundary testing, structured error diagnostics, input sanitization, zero silent failures, and regression safety.
3. **Alex Vance (Full-Stack Developer & VTT/TTRPG Specialist)**: Focuses on token budgeting, serializer output formats (JSON/XML/YAML), graph traversal depth, and developer inspection UI.
4. **Morgan "Gifford" Reed (World Anvil Migrator & Power Worldbuilder)**: Focuses on cross-link auto-resolution (`@[Title](template:id)`), category/tag filters, visual token gauges, and DM secret visibility controls.
5. **Elena Rostova (Novelist & Fiction Author)**: Focuses on multi-bucket context layers (Tone, Story Bible, Scene Slate, Chapter Beats), character relationship matrices, and style presets.
